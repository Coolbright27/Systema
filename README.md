Systema cleans up the parts of Windows that slow you down — background services, telemetry, optional preview updates, bloatware, badly-behaved apps — without breaking your PC. Every change is reversible from inside the app, and a System Restore point is created automatically before anything is touched.

## Highlights

- **Auto-Pilot** — one toggle, applies a safe optimization profile and keeps it that way
- **Privacy** — turn off telemetry, advertising ID, and data collection in one click
- **Task Sleep** — quietly throttles background apps when you're not using them
- **Game Boost** — auto-detects games and suspends non-essential services while you play
- **App Cleanup** — remove pre-installed Microsoft apps you'll never use
- **Restore** — every change is reversible; restore points created automatically

## Install

1. **[Download the latest installer →](../../releases/latest)**
2. Run it. Windows will ask for admin — required to modify system settings.
3. Open Systema from the Start menu.

That's it. The installer is ~65 MB and includes everything it needs.

## Updates

Systema updates itself automatically when your PC is idle — no prompts, no popups. You can also check manually from **Settings → Updates**.
